Algorithmic and hardware evolution (2014–2026)

Attention Mechanisms and Their Operational Cost

Scaled dot-product attention computes pairwise similarities across all \(L\) tokens, taking \(\mathcal{O}(L^2)\) compute and memory during prefill. During autoregressive decoding, caching key-value activations creates an \(\mathcal{O}(L)\) memory footprint that saturates GPU high-bandwidth memory (HBM).

Every subsequent attention architecture modifies this primitive along one of four engineering axes: preserving dense exactness via IO-aware tiling, compressing key-value cache bandwidth, restructuring positional geometry for length generalization, or sparsifying runtime query-key lookups.

Vector 1

Dense Exactness
Full \(\mathcal{O}(L^2)\) softmax attention executed via on-chip SRAM tiling to minimize HBM round trips.

Vector 2

KV Cache Compression
Head sharing (MQA, GQA), cross-layer sharing (CLA), and low-rank projection (MLA) to cut decode bandwidth.

Vector 3

Positional Geometry
Relative coordinate transforms (RoPE, ALiBi, YaRN, M-RoPE) and zero-shot context window extension.

Vector 4

Sparsity and Recurrence
Sliding windows, linear state spaces, and learned sparse routing (DeltaNet, KDA, NSA, DSA, DeepSeek-V4 CSA).

01 Sep 2014exactness

Bahdanau additive attention

Dynamic soft-alignment replaces the fixed-size vector bottleneck in encoder-decoder RNNs.

What existed

Recurrent sequence-to-sequence networks (Sutskever et al., Cho et al.) encoded the entire variable-length source sentence into a single fixed-dimensional hidden vector \(h_T \in \mathbb{R}^d\) before decoding.

The problem

Information compression into a static vector caused translation performance to collapse on sequences exceeding 20 words due to vanishing gradients and finite vector capacity.

The mechanism

At each decoder step \(i\), compute dynamic alignment energies \(e_{ij}\) between decoder state \(s_{i-1} \in \mathbb{R}^{d_s}\) and encoder states \(h_j \in \mathbb{R}^{d_h}\) via an additive multi-layer perceptron:

\[e_{ij} = v_a^\top \tanh(W_a s_{i-1} + U_a h_j), \quad \alpha_{ij} = \frac{\exp(e_{ij})}{\sum_{k=1}^{T_x} \exp(e_{ik})}, \quad c_i = \sum_{j=1}^{T_x} \alpha_{ij} h_j\]

The context vector \(c_i\) is concatenated with \(s_{i-1}\) to predict target token \(y_i\).

What it fixed

  • Created direct gradient highways between decoder step \(i\) and all source positions \(j \in [1, T_x]\).
  • Enabled soft, continuous word alignment that handles non-monotonic language word order.

What you give up

  • Sequential recurrent unrolling prevents parallel training across sequence length.
  • Evaluating additive \(\tanh\) feed-forward projections at every step incurs \(\mathcal{O}(T_x T_y)\) compute overhead.

Use it when

Building recurrent sequence-to-sequence architectures or studying historical alignment foundations.

Luong multiplicative attention

Replace additive multi-layer perceptron projections with bilinear dot-product operations.

What existed

Bahdanau additive attention evaluated alignment scores using feed-forward \(\tanh\) transformations \(v_a^\top \tanh(W_a s_{i-1} + U_a h_j)\), which required significant vector additions and activation calls.

The problem

Additive alignment calculations were computationally inefficient on GPUs compared to dense matrix-matrix multiplications, and lacked global vs local attentional flexibility.

The mechanism

Luong introduced multiplicative bilinear scoring functions and differentiated between global attention (attending to all source words) and local attention (monitored around an aligned window \([p_t - D, p_t + D]\)):

\[\text{score}(s_t, h_s) = \begin{cases} s_t^\top h_s & \text{dot} \\ s_t^\top W_a h_s & \text{general} \\ v_a^\top \tanh(W_a [s_t; h_s]) & \text{concat} \end{cases}\]

In local attention, center position \(p_t = S \cdot \operatorname{sigmoid}(v_p^\top \tanh(W_p s_t))\) is predicted dynamically with Gaussian-weighted alignment scores.

What it fixed

  • Multiplicative general scoring \(s_t^\top W_a h_s\) uses fast GPU GEMM routines instead of element-wise \(\tanh\) additions.
  • Local attention reduces per-step alignment cost from \(\mathcal{O}(T_x)\) to fixed window size \(\mathcal{O}(2D+1)\).

What you give up

  • Still constrained by underlying recurrent LSTM/GRU sequential bottlenecks during training.
  • Dot-product scoring without scaling tends to push softmax gradients toward zero in higher dimensions.

Use it when

Optimizing recurrent encoder-decoder baselines with fast bilinear matrix multiplications.

Scaled dot-product & Multi-Head Attention (MHA)

Eliminate recurrence entirely; evaluate full pairwise token interactions in parallel across split representation subspaces.

What existed

Recurrent neural networks (LSTMs, GRUs) unrolled sequential hidden states token-by-token, using attention purely as a cross-network alignment mechanism.

The problem

Sequential token dependencies \(h_t = f(h_{t-1}, x_t)\) prevented parallel execution across sequence length \(L\) on modern GPUs, capping training throughput and context scaling.

The mechanism

Compute pairwise similarity between queries \(Q \in \mathbb{R}^{L \times d_k}\) and keys \(K \in \mathbb{R}^{L \times d_k}\), scaling by \(1/\sqrt{d_k}\) to stabilize softmax variance, then project values \(V \in \mathbb{R}^{L \times d_v}\) across \(H\) parallel heads:

\[\text{MHA}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_H) W^O, \quad \text{head}_i = \operatorname{softmax}\left(\frac{Q_i K_i^\top}{\sqrt{d_k}}\right) V_i\]

Prefill computes \(QK^\top \in \mathbb{R}^{L \times L}\) in a single parallel tensor contraction requiring \(2L^2 d_k\) FLOPs per head.

What it fixed

  • Enables massive parallelization across sequence length \(L\) on GPU Tensor Cores during training.
  • Constant \(\mathcal{O}(1)\) path length between any two tokens across the sequence, avoiding gradient decay.

What you give up

  • Quadratic compute and activation memory \(\mathcal{O}(L^2)\) during prefill.
  • Linear \(\mathcal{O}(L)\) key-value cache memory growth per generation step during autoregressive decoding.

Use it when

Standard architectural foundation for Transformer training and dense representation modeling.

Absolute sinusoidal & learned positional encodings

Inject position coordinates directly into token input embeddings via fixed sinusoidal frequencies or learned parameter tables.

What existed

Recurrent networks inherently captured sequence order via sequential unrolling \(t = 1, 2, \dots, T\). Pure self-attention dot products are permutation-equivariant: shuffling tokens produces identical permuted outputs.

The problem

Without explicit position coordinates, self-attention cannot differentiate between "dog bites man" and "man bites dog".

The mechanism

Add deterministic geometric frequency vectors \(PE_{(pos, 2i)}\) or learned embedding vectors \(W_{\text{pos}} \in \mathbb{R}^{L_{\text{max}} \times d}\) directly to token embeddings \(X\):

\[PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right), \quad PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right)\]

Fixed frequencies allow the model to learn linear transformations \(PE_{pos+k} = M_k PE_{pos}\) representing relative offset \(k\).

What it fixed

  • Incorporate position awareness into self-attention with zero additional matrix multiplications.
  • Sinusoidal encodings require zero learned parameters and theoretically define coordinates for arbitrary \(pos\).

What you give up

  • Direct vector addition contaminates semantic token embeddings with coordinate signals.
  • Attention dot products expand into noisy cross-terms \(q_i k_j^\top + q_i p_j^\top + p_i k_j^\top + p_i p_j^\top\); fails to extrapolate cleanly beyond \(L_{\text{train}}\).

Use it when

Training baseline Transformers with fixed sequence lengths (e.g. original BERT, GPT-2).

Shaw relative positional representations

Modulate pairwise attention logits and value aggregations by learned relative distance vectors clipped at maximum radius.

What existed

Absolute positional encodings added static coordinate vectors to input tokens, forcing attention layers to infer relative distances \(i - j\) through cross-term interactions.

The problem

Absolute encodings do not generalize well to translation invariance: the relation between token \(i\) and \(i+2\) should be identical regardless of whether \(i=5\) or \(i=500\).

The mechanism

Inject learned relative position embeddings \(a_{ij}^K, a_{ij}^V \in \mathbb{R}^{d_k}\) directly into the self-attention equation, indexed by clipped relative distance \(\text{clip}(j - i, k) = \max(-k, \min(k, j - i))\):

\[e_{ij} = \frac{x_i W^Q (x_j W^K + a_{ij}^K)^\top}{\sqrt{d_k}}, \quad z_i = \sum_{j=1}^L \alpha_{ij} (x_j W^V + a_{ij}^V)\]

What it fixed

  • Enforces strict shift-invariance: attention depends directly on relative distance \(j - i\).
  • Improves language modeling and translation quality over absolute embeddings.

What you give up

  • Computing relative key tensors \(x_i W^Q (a_{ij}^K)^\top\) adds tensor reshape and broadcasting overhead in GPU kernels.
  • Cannot distinguish distances beyond the clipping boundary \(k\).

Use it when

Designing models where relative token distance is the dominant inductive bias (e.g. music modeling, early syntax parsing).

Sparse Transformer (Factorized Attention)

Factorize full pairwise attention matrices into separate local and strided connectivity patterns.

What existed

Standard Multi-Head Attention computed full dense \(L \times L\) attention matrices, which saturated GPU memory when scaling sequence length \(L > 2048\).

The problem

Dense \(\mathcal{O}(L^2)\) prefill compute and memory prevented training Transformers on high-resolution images, raw audio waveforms, or long documents.

The mechanism

Decompose the dense index set into two factorized subsets \(S_i^{(1)}\) (strided steps with period \(p \approx \sqrt{L}\)) and \(S_i^{(2)}\) (local neighborhood window):

\[S_i^{(1)} = \{j : (i - j) \bmod p = 0\}, \quad S_i^{(2)} = \{j : \lfloor j/p \rfloor = \lfloor i/p \rfloor\}\]

Alternating these factorized heads across layers allows information to propagate across the entire sequence in 2 steps while reducing active connections to \(\mathcal{O}(L\sqrt{L})\).

What it fixed

  • Reduces compute and memory scaling from \(\mathcal{O}(L^2)\) to \(\mathcal{O}(L\sqrt{L})\).
  • Enabled training Transformers on sequences of up to 16,384 tokens in 2019.

What you give up

  • Rigid geometric connectivity lacks data-dependent adaptation; queries cannot dynamically attend to arbitrary distant tokens.
  • Requires specialized block-sparse GPU CUDA kernels to realize wall-clock speedups.

Use it when

Processing structured, periodic inputs (audio waveforms, 2D images unrolled to 1D) with fixed stride lengths.

T5 relative position bias

Add scalar bias terms directly to attention logits with logarithmic distance bucketing.

What existed

Shaw relative embeddings added high-dimensional vectors to keys and values, requiring per-head matrix-vector multiplications during logit calculation.

The problem

Shaw's vector additions increased parameter counts and memory bandwidth traffic without improving relative rank separation beyond the clipping distance.

The mechanism

Add a learned scalar bias \(b_{\text{bucket}(j-i)}\) directly to attention logits before softmax. Relative distances are partitioned into 32 buckets: exact integer offsets for \(|j - i| < 16\), and logarithmic bins up to distance 128:

\[\text{AttnLogit}_{ij} = \frac{q_i k_j^\top}{\sqrt{d_k}} + b_{\text{bucket}(j-i)}\]

What it fixed

  • Zero vector projection overhead: simple scalar table lookup added directly to logits.
  • Logarithmic bucketing assigns fine resolution to nearby tokens and coarse resolution to distant tokens.

What you give up

  • Dense attention computation remains \(\mathcal{O}(L^2)\); does not compress the KV cache.
  • Cannot extrapolate beyond the maximum bucketed distance boundary.

Use it when

Standard architectural component in encoder-decoder models (T5, ByT5).

Multi-Query Attention (MQA)

Collapse key and value heads into a single shared head to slash memory bandwidth bottlenecks during autoregressive decoding.

What existed

Multi-Head Attention maintained \(H\) distinct query heads, \(H\) distinct key heads, and \(H\) distinct value heads across all layers.

The problem

During autoregressive decoding, generating 1 token requires loading all cached key and value tensors from GPU High-Bandwidth Memory (HBM) to SRAM for arithmetic intensity \(\approx 1\) FLOP/byte. Memory bandwidth, not compute, becomes the fundamental bottleneck.

The mechanism

Retain \(H_Q\) distinct query heads, but project only a single shared key head and single shared value head across all query heads:

\[Q \in \mathbb{R}^{L \times H_Q \times d_k}, \quad K \in \mathbb{R}^{L \times 1 \times d_k}, \quad V \in \mathbb{R}^{L \times 1 \times d_v}\]

Each query head \(i\) computes attention against the identical shared key-value pair: \(\operatorname{softmax}(Q_i K^\top / \sqrt{d_k}) V\).

What it fixed

  • Reduces KV cache size and memory bandwidth reads by factor of \(H_Q\) (e.g. \(32\times\) or \(64\times\)).
  • Massively increases maximum serving batch size and decoding throughput.

What you give up

  • Significant degradation in representational capacity and multi-head associative retrieval.
  • Forces all query heads to extract features from an identical key-value subspace.

Use it when

Serving memory-constrained edge models or latency-critical high-throughput services (e.g. PaLM, Falcon-7B).

Reformer (LSH Attention & Reversible Layers)

Replace dense similarity matrices with Locality-Sensitive Hashing and eliminate activation memory with reversible residuals.

What existed

Dense Multi-Head Attention required materializing full \(L \times L\) softmax matrices and storing intermediate activations for all \(N\) layers during backward propagation.

The problem

Long-sequence training was dual-bottlenecked: \(\mathcal{O}(L^2)\) attention compute and \(\mathcal{O}(N \cdot L \cdot d)\) activation memory stored for backpropagation.

The mechanism

Assign queries and keys to hash buckets via random angular projections \(h(x) = \arg\max([xR; -xR])\). Sort tokens by hash bucket, chunk them into blocks of size \(B\), and compute attention only within identical buckets. Combine with RevNet reversible residual layers:

\[Y_1 = X_1 + \text{Attn}(X_2), \quad Y_2 = X_2 + \text{FFN}(Y_1)\]

Activations are reconstructed on-the-fly during backpropagation, dropping activation storage from \(\mathcal{O}(N)\) to \(\mathcal{O}(1)\).

What it fixed

  • Attention compute complexity dropped from \(\mathcal{O}(L^2)\) to \(\mathcal{O}(L \log L)\).
  • Activation memory is independent of layer count \(N\).

What you give up

  • LSH bucketing is stochastic: multi-round hashing is required to avoid missing relevant key tokens.
  • Irregular bucket sizes and sorting operations cause poor GPU Tensor Core matrix utilization.

Use it when

Historical reference for sub-quadratic hashing and reversible layer memory management.

Routing Transformer

Route queries and keys dynamically to sparse attention clusters using spherical k-means.

What existed

Reformer used random static hyperplane projections (LSH) to bucket tokens, which ignored the learned geometric structure of the query-key data manifold.

The problem

Random hashing led to high variance in bucket assignments, requiring multiple hash rounds and wasting compute on empty or oversized buckets.

The mechanism

Cluster queries and keys on the unit hypersphere using online spherical \(k\)-means with orthogonal centroids \(\mu_1, \dots, \mu_k\). Tokens are routed to top cluster centroids, and attention is evaluated only within matching clusters \(C_m\):

\[\text{cluster}(x) = \arg\max_{m} \frac{x^\top \mu_m}{\|x\| \|\mu_m\|}, \quad A_{ij} = \begin{cases} \operatorname{softmax}\left(\frac{q_i k_j^\top}{\sqrt{d_k}}\right) & \text{if } j \in C_{\text{cluster}(q_i)} \\ 0 & \text{otherwise} \end{cases}\]

What it fixed

  • Content-aware clustering achieves lower perplexity than random LSH hashing.
  • Reduces attention complexity to \(\mathcal{O}(L^{1.5})\) or \(\mathcal{O}(L\sqrt{L})\).

What you give up

  • Online \(k\)-means centroid updates introduce dynamic synchronization barriers.
  • Clustering assignments are non-differentiable and sensitive to cluster collapse.

Use it when

Exploring content-based sparse routing algorithms for long-sequence modeling.

Longformer (Sliding Window + Global Attention)

Construct a linear-complexity attention pattern combining local sliding windows, dilated gaps, and task-specific global tokens.

What existed

Full dense attention limited BERT-like models to 512 tokens due to \(\mathcal{O}(L^2)\) memory and compute constraints.

The problem

Document-level NLP tasks (QA, document summarization, legal text analysis) require thousands of tokens of context that dense Transformers could not ingest.

The mechanism

Combine three distinct attention patterns: sliding window of size \(w\), dilated sliding window with stride \(d\), and selected global attention on task tokens \(G\) (e.g. `[CLS]` or question tokens):

\[A_{ij} = \begin{cases} \operatorname{softmax}\left(\frac{q_i k_j^\top}{\sqrt{d_k}}\right) & \text{if } |i - j| \le w/2 \text{ or } i, j \in G \\ 0 & \text{otherwise} \end{cases}\]

Total compute scales linearly as \(\mathcal{O}(L \times (w + |G|))\).

What it fixed

  • Strict linear \(\mathcal{O}(L)\) scaling allows scaling document context to 4,096+ tokens.
  • Global tokens preserve full bidirectional cross-talk for classification and QA heads.

What you give up

  • Requires manually designating which token indices receive global attention.
  • Non-global tokens cannot perform direct single-layer associative retrieval across long distances.

Use it when

Document-level encoder tasks (classification, question answering over long forms).

Linformer (Low-Rank Key-Value Projections)

Project key and value sequence length dimension to a fixed low-rank dimension k via linear projection matrices.

What existed

Standard self-attention computes an \(L \times L\) matrix \(QK^\top\), maintaining full length \(L\) across queries, keys, and values.

The problem

The full \(L \times L\) attention matrix exhibits low-rank spectral decay in practice, yet dense attention evaluates all \(L^2\) pairwise interactions.

The mechanism

Project the sequence dimension of keys \(K\) and values \(V\) from length \(L\) down to a fixed low rank \(k \ll L\) using learned projection matrices \(E_i, F_i \in \mathbb{R}^{k \times L}\):

\[\bar{K} = E_i K \in \mathbb{R}^{k \times d_k}, \quad \bar{V} = F_i V \in \mathbb{R}^{k \times d_v}, \quad \text{head}_i = \operatorname{softmax}\left(\frac{Q \bar{K}^\top}{\sqrt{d_k}}\right) \bar{V}\]

The attention matrix size drops from \(L \times L\) to \(L \times k\), achieving \(\mathcal{O}(L \cdot k)\) linear time and memory complexity.

What it fixed

  • Linear \(\mathcal{O}(L)\) compute and memory complexity during prefill.
  • Directly exploits low-rank matrix spectral properties without complex kernels.

What you give up

  • Fixed projection matrices \(E, F\) bind the model to a predetermined maximum sequence length during training.
  • Cannot be applied straightforwardly to causal autoregressive decoding where future tokens are unknown.

Use it when

Bidirectional encoder models with fixed sequence length targets.

Linear attention via kernel feature maps

Decompose softmax normalization into associative feature maps to reorder matrix multiplication from quadratic to linear complexity.

What existed

Softmax attention \(\operatorname{softmax}(QK^\top)V\) required materializing the full \(L \times L\) matrix first due to non-linear row-wise normalization.

The problem

Evaluating \((QK^\top)V\) costs \(\mathcal{O}(L^2 d)\) operations and \(\mathcal{O}(L)\) memory per step during generation, precluding real-time streaming.

The mechanism

Replace \(\exp(q_i^\top k_j / \sqrt{d})\) with a kernel dot product \(\phi(q_i)^\top \phi(k_j)\) (e.g. \(\phi(x) = \operatorname{elu}(x) + 1\)). Using matrix associativity, reorder the computation from \((\Phi(Q)\Phi(K)^\top)V\) to \(\Phi(Q)(\Phi(K)^\top V)\):

\[S_t = S_{t-1} + \phi(k_t) v_t^\top, \quad z_t = z_{t-1} + \phi(k_t), \quad o_t = \frac{\phi(q_t)^\top S_t}{\phi(q_t)^\top z_t}\]

The recurrent state \(S_t \in \mathbb{R}^{d_k \times d_v}\) maintains fixed \(\mathcal{O}(1)\) memory footprint over unbounded sequence streams.

What it fixed

  • Linear \(\mathcal{O}(L)\) prefill compute and constant \(\mathcal{O}(1)\) decode time and memory.
  • Unifies recurrent neural networks and parallel self-attention into a single formulation.

What you give up

  • Unbounded linear summation causes state saturation and catastrophic memory decay.
  • Lacks the sharp, focused query-key routing of exponential softmax attention on language modeling.

Use it when

Building real-time linear-time RNN alternatives or high-throughput audio/visual processing pipelines.

Katharopoulos et al. · Transformers are RNNs: Fast Autoregressive Transformers with Linear AttentionarXiv:2006.16236 · submitted 29 Jun 2020

BigBird

Combine random graph connections, sliding window attention, and global tokens to preserve universal sequence approximation.

What existed

Sparse heuristic patterns (Longformer, Sparse Transformer) achieved linear complexity but lacked theoretical guarantees of preserving the expressive power of full Transformers.

The problem

Arbitrary sparse graphs can fail to maintain Turing completeness or universal function approximation properties, leading to representation collapse on complex graph and logic tasks.

The mechanism

Formulate sparse attention as a random graph consisting of three complementary edge sets: a local sliding window \(W\), \(r\) random connections per token, and \(g\) global memory tokens:

\[A_{ij} = \begin{cases} \operatorname{softmax}\left(\frac{q_i k_j^\top}{\sqrt{d_k}}\right) & \text{if } |i - j| \le w \text{ or } j \in \text{Random}(i) \text{ or } i, j \in \text{Global} \\ 0 & \text{otherwise} \end{cases}\]

Zaheer et al. proved that this tripartite graph construction preserves universal approximation and Turing completeness with \(\mathcal{O}(L)\) complexity.

What it fixed

  • Theoretical proof of universal sequence approximation with linear \(\mathcal{O}(L)\) complexity.
  • Enables scaling context windows up to \(8\times\) on standard GPU hardware for long document QA and genomics.

What you give up

  • Random memory gathering requires custom GPU kernels to avoid memory serialization.
  • Autoregressive causal generation with random backward edges introduces caching complexity.

Use it when

Long-document bidirectional encoding tasks requiring theoretical universal approximation guarantees (e.g. genomics, long text summarization).

Performer (FAVOR+)

Approximate standard softmax attention unbiasedly using Positive Orthogonal Random Features.

What existed

Linear attention mechanisms used simple polynomial/ELU kernels that deviated significantly from the exponential softmax distribution.

The problem

Ad-hoc linear kernels failed to match the language modeling perplexity of pretrained softmax Transformers and could not reuse pretrained Transformer weights.

The mechanism

FAVOR+ estimates \(\exp(q^\top k / \sqrt{d})\) using orthogonal random feature vectors \(\omega_i \sim \mathcal{N}(0, I_d)\) with positive non-linear projections:

\[\phi(x) = \frac{h(x)}{\sqrt{M}} [\exp(\omega_1^\top x - \|x\|^2/2), \dots, \exp(\omega_M^\top x - \|x\|^2/2)]^\top\]

Enforcing strictly positive feature mappings avoids catastrophic negative variance estimates while enabling associative \(\mathcal{O}(L \cdot M)\) computation.

What it fixed

  • Provably unbiased approximation of exact softmax attention with linear scaling.
  • Can transfer pretrained dense Transformer checkpoints into linear attention without retraining from scratch.

What you give up

  • Monte Carlo variance requires \(M \ge 256\) random projections per head, increasing intermediate tensor memory.
  • Random features must be periodically redrawn during training to prevent projection overfitting.

Use it when

Linearizing pretrained dense Transformer models without architectural surgery.

Nyströmformer

Approximate the full self-attention matrix in linear time using the classical Nyström landmark matrix decomposition.

What existed

Kernel-based linear attention and LSH hashing required either Monte Carlo random projections or stochastic hash binning.

The problem

Random feature approximations introduced sampling noise, while low-rank methods (Linformer) could not adapt dynamically to variable sequence lengths.

The mechanism

Sample \(m\) landmark tokens (e.g. \(m = 64\)) from the sequence using segment-mean pooling. Approximate full attention \(A = \operatorname{softmax}(QK^\top / \sqrt{d_k})\) via Nyström matrix reconstruction:

\[\tilde{A} = A_{L, m} A_{m, m}^{+} A_{m, L}\]

where \(A_{L,m}\) is attention between all tokens and landmark keys, \(A_{m,m}^{+}\) is the Moore-Penrose pseudoinverse (computed via iterative Schulz updates), and \(A_{m,L}\) is landmark-to-token attention. Total complexity scales as \(\mathcal{O}(L \cdot m)\).

What it fixed

  • \(93.3\%\) KV cache reduction compared to standard Multi-Head Attention.
  • Preserves full multi-head query expressiveness (\(H = 128\) heads) without head-sharing capacity loss.
  • Significantly increases maximum inference batch sizes and throughput on long-context workloads.

  • Requires low-rank matrix pretraining from scratch; cannot be easily converted from existing MHA/GQA checkpoints.
  • Additional projection algebra increases compute overhead during prefill phases.

Cross-Layer Attention (CLA)

Share key-value projections across adjacent Transformer layers to cut the total KV cache footprint by an additional 2x.

What existed

GQA and MQA compressed key-value heads within each individual layer, but maintained independent KV states across all \(N\) layers in the stack.

The problem

Key-value activations in adjacent layers exhibit high cosine similarity and redundant feature representations, multiplying HBM memory footprint across layer depth.

The mechanism

Share key and value projection tensors across \(r\) adjacent layers (e.g. \(r = 2\)). Layer \(l\) computes queries \(Q_l\) from hidden state \(h_l\), but reuses key-value tensors \(K_{\lfloor l/r \rfloor \cdot r}, V_{\lfloor l/r \rfloor \cdot r}\) generated by the anchor layer:

\[\text{KVCache}_{l} = \text{KVCache}_{l-1} \quad \text{for } l \bmod r \ne 0\]

Combining CLA (\(2\times\)) with GQA (\(8\times\)) achieves a compound \(16\times\) KV cache reduction.

What it fixed

  • Cuts total model KV cache memory by another \(2\times\) with virtually zero loss in benchmark perplexity.
  • Doubles serving throughput for long-context generation workloads.

What you give up

  • Requires training from scratch or specialized adaptation fine-tuning.
  • Slightly constrains layer-specific feature specialization in upper layers.

Use it when

Maximizing KV cache memory reduction in deep Transformer architectures.

Contextual Position Encoding (CoPE)

Count dynamic contextual units such as words or sentences via attention weights rather than static token coordinates.

What existed

All positional encodings (RoPE, ALiBi, learned) incremented coordinates strictly by raw token index \(i = 1, 2, 3, \dots\).

The problem

Token count is an arbitrary artifact of the tokenizer: a single word or entity may be split into 1, 2, or 5 sub-tokens, corrupting structural distance reasoning (e.g. "find the 3rd sentence").

The mechanism

Compute dynamic position increments \(g_{ij} = \operatorname{sigmoid}(q_i^\top k_j / \sqrt{d_k})\) representing whether token \(j\) marks a contextual boundary. The contextual distance \(p_{ij}\) between token \(i\) and token \(j\) is the sum of gate activations:

\[p_{ij} = \sum_{k=j}^i g_{ik}, \quad e_{ij} = \frac{q_i k_j^\top}{\sqrt{d_k}} + \operatorname{Interpolate}(e[\lfloor p_{ij} \rfloor], e[\lceil p_{ij} \rceil], p_{ij})\]

Positions advance dynamically based on content semantics rather than raw token indices.

What it fixed

  • Allows attention heads to count semantically meaningful units (sentences, words, code blocks) directly.
  • Significantly outperforms RoPE on counting tasks, selective copy, and structured document reasoning.

What you give up

  • Computing cumulative gate sums \(p_{ij}\) adds kernel complexity during training.
  • Requires dedicated custom kernels to execute efficiently in autoregressive decoding.

Use it when

Building models for structured document querying, code AST reasoning, and semantic counting.

DeltaNet

Parallelize the error-correcting delta rule across sequence length via chunkwise Householder formulations.

What existed

The delta rule provided superior associative recall and dynamic memory overwriting, but its sequential matrix update \(S_t = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top\) could not be parallelized efficiently on GPUs.

The problem

A recurrent memory that cannot scale its training compute across sequence length cannot compete with parallel Transformers at foundation model scale.

The mechanism

DeltaNet constructs a hardware-efficient parallel algorithm for the delta rule using Householder-like matrix product representations. Chunking sequence length into blocks of size \(B = 64\), intra-chunk state updates are evaluated as dense matrix multiplications on Tensor Cores:

\[S_{[b]} = S_{[b-1]} (I - K_b^\top T_b K_b) + V_b^\top (I - T_b K_b K_b^\top) K_b\]

where \(T_b = (I + \operatorname{triu}(K_b K_b^\top \odot \beta_b))^{-1} \operatorname{diag}(\beta_b) \in \mathbb{R}^{B \times B}\) is computed strictly within fast on-chip SRAM, while inter-chunk states propagate via parallel associative prefix scans.

What it fixed

  • Scales error-correcting linear attention to multi-billion parameter foundation models.
  • Significantly outperforms standard linear attention and Mamba on multi-query associative recall tasks.
  • Constant \(\mathcal{O}(1)\) autoregressive decoding time and memory.

What you give up

  • Implementation requires complex custom GPU kernels for chunkwise Householder factorization.
  • Compressed state still exhibits finite capacity limits on massive-needle retrieval.

Use it when

Building high-throughput recurrent or hybrid architectures that require high-precision associative memory.

DeepSeek Native Sparse Attention (NSA)

Combine coarse token compression, fine-grained top-k block selection, and sliding windows natively on Tensor Cores.

Tri-branch sparse hierarchy: coarse compressed tokens provide global context, top-k selected blocks capture fine-grained associations, and a sliding window preserves local continuity.

What existed

Prior sparse attention algorithms used irregular, token-level point gathering that caused GPU thread divergence and poor Tensor Core matrix utilization.

The problem

Theoretical FLOP reductions from sparse patterns were wiped out in wall-clock execution time by memory fragmentation and low hardware efficiency.

The mechanism

NSA is natively designed for Tensor Core block tiling using three parallel attention branches per head:

\[\text{NSA}(Q, K, V) = \text{Attn}_{\text{compressed}}(Q, K^C, V^C) + \text{Attn}_{\text{selected}}(Q, K^S, V^S) + \text{Attn}_{\text{window}}(Q, K^W, V^W)\]

1. Compressed branch: Blocks of length \(S\) are compressed into single key-value vectors via learned intra-block pooling.
2. Selected branch: Top-\(k\) most relevant fine-grained blocks (size 64) are selected dynamically via coarse query scoring.
3. Sliding window: Local window of size \(W\) handles adjacent context.

What it fixed

  • Massive wall-clock prefill and decode speedups on 64k–1M sequence lengths.
  • Hardware-aligned block operations (size 64) maintain full Tensor Core matrix utilization.
  • Trained natively end-to-end rather than patched post-hoc on dense checkpoints.

What you give up

  • Tri-branch routing and kernel dispatch add significant architectural and implementation complexity.
  • Requires pretraining from scratch with custom forward and backward sparse kernels.

Hardware Constraints and Architecture Selection

Attention architecture selection is determined by two hardware bottlenecks: compute-bound prefill (FLOP limits) and bandwidth-bound decoding (HBM transfer limits):

Prefill Bottleneck (Compute-Bound)

Processing prompt length \(L\) requires \(\mathcal{O}(L^2)\) FLOPs. On GPUs, Tensor Core saturation is maximized via IO-aware SRAM tiling (FlashAttention-1/2/3). For \(L \ge 64\text{k}\), compute scaling mandates structural sparsity (NSA, DSA, DeepSeek-V4 CSA) or linear recurrence (DeltaNet, KDA, GLA).

Decode Bottleneck (Memory-Bound)

Generating token-by-token requires loading the entire KV cache from HBM to SRAM for arithmetic intensity \(\approx 1\) FLOP/byte. Serving throughput is directly proportional to KV cache compression (MQA, GQA, CLA, MLA).

Context Extrapolation Bottleneck (Geometry-Bound)

Evaluating sequences beyond training bounds causes positional distribution shifts. Additive coordinates (learned, sinusoidal) fail catastrophically; rotational geometry requires frequency-banded scaling (YaRN, LongRoPE, M-RoPE) or complete positional dropping (DroPE).
